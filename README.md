## ✨ Highlights

- **Signature VIPBOT Aesthetic:** Clean rounded Unicode frames (`╭┄〔 ... 〕┄╮`, `┆`, `╰┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄╯`) with curated `💎`, `👑`, `⚜️`, `✦` accents.
- **Autosession & Linking:** Supports `VIPBOT:` (and legacy `WOLF-BOT:`) session tokens, interactive pairing code, and QR terminal login.
- **2,000+ Commands:** Menus, owner controls, group administration, AI tools, media downloaders, stickers/ephoto, games, automation, and utility suites.
- **Multi-Database Persistence:** Local SQLite (`better-sqlite3` with `sql.js` WASM fallback) plus optional PostgreSQL (`DATABASE_URL`) and MongoDB (`MONGODB_URI`) mirrors.
- **Built-in Web Dashboard:** Express dashboard on port `3000` providing live status, pairing UI, and real-time console logs.

## 🚀 Quick Start

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Configure environment (`.env`):**
   ```env
   BOT_NAME="VIPBOT"
   OWNER_NAME="Lupin Stanley"
   OWNER_NUMBER="255780470905"
   BOT_PREFIX="."
   BOT_MODE="public"
   SESSION_ID="VIPBOT:~your_session_payload"
   ```

3. **Start VIPBOT:**
   ```bash
   npm start
   ```
